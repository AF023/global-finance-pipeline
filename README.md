# 🌍 Global Finance Analytics Pipeline & Modern Data Stack Simulator

## 📌 Overview
This project demonstrates an automated **Modern Data Stack (MDS)** pipeline designed to ingest, transform, and analyze global exchange rates in real-time. Built using **Python**, **Pandas**, and **DuckDB**, this project simulates an enterprise-grade analytics engineering workflow.

---

## 🏗️ Architecture & Tech Stack
- **Python & Requests:** Extracts raw JSON exchange rate data from a live open API.
- **Pandas:** Handles data manipulation, schema alignment, and timestamp enrichment.
- **DuckDB:** Functions as a high-performance, embedded analytical Data Warehouse.

---

## 📂 Repository Content
- `global_finance_pipeline.ipynb`: Complete Google Colab / Jupyter Notebook containing data extraction, Pandas transformation, and DuckDB loading operations.

---

## 📊 Key Insights & Analytics Value
- Ingests macroeconomic indicators automatically for global financial reporting.
- Standardizes multi-currency metrics against USD to feed BI Dashboards (Power BI / Tableau).
- Provides scalable schema definitions for currency valuation and tracking.

---

## 🚀 How to Run
Open `global_finance_pipeline.ipynb` directly in Google Colab or any Jupyter environment and run all cells sequentially.
